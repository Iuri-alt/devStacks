# 🚀 DevStacks

Um sistema simples de gerenciamento de tarefas com login, desenvolvido usando HTML, CSS e JavaScript.

## 🔐 Funcionalidades

* Sistema de login
* Adição de tarefas com data
* Marcar tarefas como concluídas
* Exclusão de tarefas
* Persistência de dados com LocalStorage
* Proteção de rota

## 🖥️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 🌐 Acesse o projeto

👉 https://seu-usuario.github.io/devstacks/

## 📚 Aprendizados

Este projeto foi desenvolvido para praticar:

* Manipulação do DOM
* Eventos em JavaScript
* Armazenamento local
* Estruturação de projetos front-end
